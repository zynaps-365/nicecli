# nicecli

Небольшая Go-библиотека для оформления вывода в терминале: строки с рамкой, анимированный спиннер и сообщения об успешном выполнении. Использует только стандартную библиотеку Go.

## Установка

Требуется Go 1.26.3 или новее, как указано в `go.mod`.

В каталоге вашего Go-модуля выполните:

```sh
go get github.com/zynaps-365/nicecli
```

## Строка с рамкой

`Print(s string)` выводит строку между двумя полосами из звёздочек:

```go
package main

import "github.com/zynaps-365/nicecli"

func main() {
	nicecli.Print("Hello!")
}
```

Результат:

```text
******
Hello!
******
```

## Спиннер

`Spinner(message string, fn func() string) string` запускает `fn` в отдельной горутине и показывает фиолетовый спиннер с сообщением, обновляя его каждые 100 мс. Вызов `Spinner` ожидает завершения `fn`, очищает текущую строку и возвращает результат функции.

```go
package main

import (
	"time"

	"github.com/zynaps-365/nicecli"
)

func main() {
	name := nicecli.Spinner("Loading...", func() string {
		time.Sleep(2 * time.Second)
		return "Admin"
	})

	nicecli.Success("Data received! Hi, %s!", name)
}
```

## Сообщение об успехе

`Success(format string, a ...interface{})` выводит зелёную галочку и сообщение с переводом строки. Форматирование аргументов работает как в `fmt.Printf`:

```go
nicecli.Success("Saved %d files", 3)
```

Результат (галочка отображается зелёным):

```text
✔ Saved 3 files
```

## Запуск примеров и проверка

Из корня репозитория:

```sh
go run ./examples/print
go run ./examples/spinner
go test ./...
go vet ./...
```

Пример спиннера выполняется около пяти секунд. Автоматических тестов пока нет; `go test ./...` проверяет компиляцию пакетов.

## Текущее поведение и ограничения

- Все функции пишут в стандартный вывод (`stdout`).
- Цвета и очистка строки используют ANSI-последовательности. Нужен терминал с их поддержкой; при перенаправлении вывода в файл эти последовательности также попадут в файл.
- Спиннер использует Unicode-символы; их отображение зависит от шрифта терминала.
- Во время работы спиннера избегайте другого вывода в тот же терминал: сообщения могут смешиваться с анимацией.
- `Spinner` принимает функцию, возвращающую только `string`. Передача ошибки и отмена операции через `context.Context` не предусмотрены.
- `Print` рассчитан на однострочный текст. Длина полосы определяется количеством Unicode-кодовых точек, поэтому для некоторых эмодзи, иероглифов и комбинируемых символов её ширина может не совпадать с шириной текста в терминале.
